# Employee Management System

A simple Employee Management System developed using Go.

## Features

* Add an employee
* Search for an employee
* Display all employees
* Delete an employee

## Technologies Used

* Go

## How to Run

go run .


## Project Structure


employee-management/
├── main.go
├── employee.go
└── README.md


## Description

This is a simple command-line application for managing employee information using Go.
