COST OPTIMIZATION TIPS:
  1. Use free tier (12 months): t2.micro EC2, db.t3.micro RDS, 5GB S3
  2. Use Reserved Instances for production (save 30-60%)
  3. Set up AWS Budgets alerts at $5, $20, $50
  4. Stop dev instances when not in use
  5. Use S3 Lifecycle rules to archive old reports
  6. Monitor with Cost Explorer weekly
  7. Use Spot Instances for non-critical workloads
  8. Right-size instances based on CloudWatch CPU metrics

COMMANDS:
  aws ce get-cost-and-usage \
    --time-period Start=2024-01-01,End=2024-01-31 \
    --granularity MONTHLY \
    --metrics "BlendedCost" \
    --group-by Type=DIMENSION,Key=SERVICE

  aws budgets create-budget \
    --account-id YOUR_ACCOUNT_ID \
    --budget file://budget.json
