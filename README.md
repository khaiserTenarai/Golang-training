# Go Employee Management System

A command-line Employee Management System developed using the Go programming language.

This project is created to practice and demonstrate fundamental Go programming concepts, including variables, data types, functions, loops, conditions, switch statements, slices, maps, and CRUD operations.

## Features

* Employee creation
* Employee lookup
* Employee update
* Employee deletion
* Menu-driven operations
* Slice-based employee management
* Map-based employee lookup

## Concepts Covered

* Variables and constants
* Primitive data types
* Type conversion
* Functions
* Conditional statements
* `for` loops
* `switch` statements
* Slices
* Maps
* Variable scope and shadowing
* CRUD operations
* User input handling

## Getting Started

### Prerequisites

Install Go on your system.

Verify the installation with:

```bash
go version
```

### Run the Project

Once the Go application is implemented, run it using:

```bash
go run main.go
```
