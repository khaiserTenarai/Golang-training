# Go Employee Management System

A beginner-friendly Employee Management System built with **Go (Golang)**. This project is also used to practice a complete **Git and GitHub workflow**, including branching, commits, merging, conflict resolution, pushing, pulling, and release tagging.

## 📌 Project Overview

The project demonstrates basic employee management functionality using Go.

It is designed as a learning project to practice both:

* Go programming fundamentals
* Git and GitHub version control

## 🛠️ Technologies Used

* Go (Golang)
* Git
* GitHub
* Go Modules

## ✨ Features

* Create employee records
* View employee records
* Update employee information
* Delete employee records
* Store employee data using Go slices
* Practice Git branching and merging
* Practice Git conflict resolution
* Push and manage the project on GitHub
* Create release tags

## 📂 Project Structure

```text
employee-management/
│
├── go.mod
├── main.go
└── README.md
```

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone <repository-url>
```

### 2. Navigate to the Project

```bash
cd employee-management
```

### 3. Run the Go Application

```bash
go run .
```

## 🔄 Git Workflow

This project demonstrates the following Git workflow:

```text
Working Tree
     ↓
Staging Area
     ↓
Commit
     ↓
Branch
     ↓
Merge
     ↓
GitHub
     ↓
Tag / Release
```

The following Git concepts are practiced:

* `git init`
* `git status`
* `git add`
* `git commit`
* `git diff`
* `git show`
* `git restore`
* `git branch`
* `git switch`
* `git merge`
* Merge conflict resolution
* `git fetch`
* `git pull`
* `git push`
* `git tag`

## 🌿 Branches

The project will use feature branches such as:

```text
main
│
├── feature/employee
│
└── feature/report
```

Feature branches are used to develop functionality independently before merging changes into the main branch.

## 📝 Commit History

The project will contain multiple meaningful commits demonstrating incremental development.

Example:

```text
Add employee structure
Add employee creation
Add employee update functionality
Add employee deletion functionality
Add project documentation
```

## 🏷️ Release Tags

An annotated Git tag will be created to mark a project release.

Example:

```text
v1.0.0
```

## 🎯 Learning Objectives

By completing this project, the following Git and GitHub concepts will be practiced:

1. Repository initialization
2. Working tree and staging area
3. Meaningful commits
4. Viewing changes with `git diff`
5. Inspecting commits with `git show`
6. Restoring changes
7. Creating feature branches
8. Merging branches
9. Resolving merge conflicts
10. Working with GitHub
11. Fetching and pulling changes
12. Creating release tags
13. Following a complete Git workflow

## 📚 Purpose

This project is created for educational purposes to gain practical experience with **Go, Git, and GitHub**.
