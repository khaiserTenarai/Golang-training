Day 14 — Gin Employee REST API

Task 13: This page is served as a static file by Gin.

API Endpoints

GET /api/employees — List all
GET /api/employees/:id — Detail
POST /api/employees — Create (JSON)
POST /api/employees/form — Create (Form)
PUT /api/employees/:id — Full update
PATCH /api/employees/:id — Partial update
DELETE /api/employees/:id — Delete

Query Parameters

?name=piyush&department=Engineering&min_salary=50000&sort_by=salary&sort_order=desc&page=1&page_size=2
