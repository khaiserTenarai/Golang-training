# Day 16 — Employee Management GraphQL API (Go)

A complete GraphQL API implementation built with Go using `graphql-go` and `graphql-go/handler`.

## Requirements Covered
1. GraphQL Schema
2. Employee Type
3. Department Type
4. Single Employee Query
5. Employee List Query
6. Create Employee Mutation
7. Update Employee Mutation
8. Delete Employee Mutation
9. GraphQL Scalar Types (`ID`, `String`, `Float`, `Boolean`, `Int`)
10. Input Types (`CreateEmployeeInput`, `UpdateEmployeeInput`)
11. Query Arguments
12. GraphQL Variables Support
13. Resolvers & Nested Resolvers (`Employee.department`)
14. Error Handling
15. Day 16 Mini Project Integration
